Which one should I use?

Use the implementation closest to the code that already handles your build form.

Language Best fit Form behavior Server required
JavaScript Static sites and browser apps Updates immediately in the browser No

Run the examples locally

Each download includes the generator and a working form. The examples display the exact JSON that is encoded.

cd php
